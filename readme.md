### 🧭 [codemap](https://github.com/syahrul84/codemap) — project index MCP server for AI coding
**Stop Claude from guessing about your codebase.** A single Rust binary that indexes a Laravel, Vue 2/3, Nuxt 2/3/4 or Next.js project and serves the facts to Claude Code over MCP.

- PHP symbols, routes, Eloquent models, and the DB schema rebuilt from migrations — all with `file:line`
- Vue/Nuxt/React components with props, emits, slots and who renders them
- Frontend ↔ backend checks: API calls to endpoints that don't exist, wrong HTTP methods, fields the UI reads that the API never returns
- Missing translation keys per locale, Filament admin pages, config/env problems
- Find usages — including which tests to run
- Answers are facts or an explicit `found: false` — never guesses. Saves tokens, cuts hallucinations, reuses existing code

`Rust` · `MCP` · macOS / Linux / Windows (WSL or Docker)

### 🧹 [CleanUp](https://github.com/syahrul84/cleanUp) — the honest Mac cleaner
**A free Mac cleaner with no snake oil.** Everything goes to the Trash, never permanently deleted.

- Smart Scan, Junk Cleaner (incl. Xcode, npm, pip, Homebrew caches), Duplicate Finder, Large & Old Files
- App Uninstaller that also removes leftovers; Leftover Finder for apps deleted long ago
- Memory Watch alerts, startup items, menu bar organizer, Homebrew manager
- Menu bar widget: live CPU, memory, disk, temperature and fan
- No fake "RAM optimizer", no subscription, no tracking

`Swift` · `SwiftUI` · macOS 14+ · Universal

### 🐳 [Colibar](https://github.com/syahrul84/colibar) — Colima in your menu bar
**Your Colima containers, one click away.** A native Docker Desktop–free control panel.

- Start/stop the VM, a whole Compose project, or one container
- Containers grouped by Compose project (great for Laravel Sail), live CPU/RAM
- Health alerts for failing healthchecks, restart loops and full disks
- Free local `https://myapp.test` domains with a built-in reverse proxy and local CA — like Valet, for containers
- ~1 MB native binary, no dependencies

`Swift` · `SwiftUI` · macOS 14+
